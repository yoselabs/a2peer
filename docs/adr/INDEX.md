# Decisions

Generated by `blueprint adr-index`; never edit by hand. Each line is a decision in force.
This index is what you need to work. Open an ADR file only to challenge or change its decision:
the file holds the reasons, the rejected options and the history.

## architecture

- [0002](0002-read-only-in-real-folder.md) **Read-only advisors run in the caller's real folder**: Read-only advisors work in the caller's real folder with no copy, guarded by the vendor's read-only mode and a git status check before and after each turn; only worker advisors get a git worktree.
- [0003](0003-mcp-interface.md) **The interface is an MCP server over one core**: a2peer is a Python MCP server (FastMCP) with a thin CLI over the same core; one codebase serves local stdio and remote HTTP, each with its own SQLite.

## domain

- [0001](0001-advisor-sessions.md) **One advisor session per caller chat and advisor**: Each (caller chat, advisor) pair has one retained advisor session; topics are tags inside it, and a new caller chat starts fresh advisor sessions.
