# a2peer

Consult other agents as advisors from one agent session, over MCP: a second opinion, a debate, or
a delegated task. Each advisor runs in its vendor's own tool (Grok Build, Codex CLI, Claude Code)
on the subscription you already have.

Status: design stage. See `docs/design.md`.

## Develop

```bash
make bootstrap
uv sync
make check
```
